# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a vulnerability

Please do not open a public issue for security problems.
Email **support@watsy.me** with the details and steps to reproduce. You will get a reply within 3 business days.

Never include live API keys (`wsy_live_...`) or webhook secrets in a report.
